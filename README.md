\# Chipboard Integer Visualizer

BSc Thesis Project - Using Chipboard Models to Teach Integers | CS50P Final Project



\## Concept

This project visualizes integer operations using physical chipboard models:

\- ⚫ Black chip = +1

\- 🔴 Red chip = -1

\- Black + Red = 0 (Zero pair cancels out)



\## File

\- `chipboard\\\\\\\\\\\\\\\_integer\\\\\\\\\\\\\\\_viz.py` - Interactive visualization of integer addition/subtraction



\## How it Works

The program simulates chipboard manipulatives used to teach:

1\. Addition of integers

2\. Subtraction as adding the opposite

3\. Zero-pair cancellation concept
